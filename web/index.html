Nothing is uploaded. The file is read in this browser, drawn on the map and registered as a table, so the SQL workspace, the toolbox and the assistant can all reach it. A CSV needs a longitude and a latitude column - lon/lat, x/y or easting/northing - or a WKT geometry column.

Earth Engine

Search the full Earth Engine catalogue and draw any of it over Ghana. Runs against your own Earth Engine account, so the quota and the terms are yours.

The Cloud project you registered with Earth Engine. Work runs against it, so this one is yours and cannot be shared. Get one free for non-commercial use at code.earthengine.google.com.

This deployment has no OAuth client configured, so it cannot offer a sign-in of its own and is asking you for one. If you run this site, set EE_CLIENT_ID once in the build and nobody is asked again. How to make one.

  1. In the Google Cloud console, pick the project already registered for Earth Engine, or register one at code.earthengine.google.com.
  2. APIs & Services → Credentials → Create credentials → OAuth client ID → Web application.
  3. Under Authorised JavaScript origins add .
  4. Copy the client ID it gives you into the box above.
  5. Audience → Test users → Add users, and add the Google account you will sign in with. While the consent screen is in testing, only listed accounts may sign in; everyone else is refused with access_denied.

Both values stay in this browser. Nothing is sent anywhere except Google, and the sign-in is read-only.

Terrain

Ghana rises from sea level to about 885 m at Mount Afadja. At true scale that is almost invisible across a country 670 km deep, so relief here is deliberately overstated. Read it as shape, never as height.

Asking questions

Optional. The key is kept in this browser and sent only to the provider you choose. Leave it empty to use this site's own endpoint if one is configured, or the built-in question patterns if not. A custom base URL must also be allowed by the site's content security policy.

Dimension

Buildings rise by their real height in metres. Districts and the analysis layers rise by the value being mapped, so magnitude is read as height rather than only as colour.

Projection

The basemap supplies world context: coastlines, neighbouring countries and place names. Choosing None removes every third-party request and leaves only the boundaries published with this site.

About

Open spatial data for Ghana: 16 regions, 260 districts, buildings, roads, facilities and terrain, in one database with one set of conventions.

Everything shown here is queryable in SQL, downloadable as GeoParquet, and servable as vector tiles.

Reading the data

Distances are straight-line, not travel time. Flood exposure is derived from observed historical surface water and terrain; it is not a modelled flood risk and carries no return period. Population is modelled from census totals rather than counted.

Administrative units join on p-codes, not names: GH07 is Greater Accra and GH0701 a district within it.
